# Autos Social Manager — sitio institucional

Sitio público con información de la herramienta y sus documentos de privacidad y uso.

## Activar GitHub Pages

1. Abrir **Settings → Pages** en este repositorio.
2. En **Build and deployment**, elegir **Deploy from a branch**.
3. Seleccionar la rama **main** y la carpeta **/(root)**.
4. Guardar y esperar a que GitHub publique el sitio.

URL esperada: https://rodrigozabala-cmd.github.io/autos-social-manager-site/

Páginas:
- Inicio: `index.html`
- Privacidad: `privacy.html`
- Términos: `terms.html`

Antes de presentar la aplicación a TikTok, revisar que las políticas reflejen fielmente el tratamiento de datos y que ambas páginas sean accesibles públicamente.
