Política de privacidad

Última actualización: 18 de noviembre de 2026.

Esta política describe el tratamiento de información relacionado con el sitio institucional de Autos Usados San Miguel y las herramientas internas utilizadas para organizar inventario y preparar contenido para redes sociales.

Información que puede tratarse

La herramienta puede procesar datos comerciales de vehículos (por ejemplo, marca, modelo, año, kilometraje, precio, descripción y fotografías), así como información técnica necesaria para administrar las cuentas y publicar contenido autorizado. No está diseñada para recopilar datos sensibles de compradores ni para crear perfiles de consumidores.

Finalidad

La información se utiliza para administrar el inventario del comercio, preparar y revisar publicaciones, seleccionar material multimedia y gestionar publicaciones en los canales sociales que el titular conecte y autorice.

Servicios de terceros

La operación puede involucrar servicios de Google, GitHub y las plataformas sociales conectadas (por ejemplo, Meta/Facebook/Instagram y, si se habilita, TikTok o Threads). Esos proveedores procesan información conforme a sus propias políticas y condiciones. No se publican credenciales ni tokens de acceso en este sitio web.

Seguridad y conservación

Se aplican controles de acceso y se procura limitar la información a la necesaria para las finalidades indicadas. Los datos se conservan mientras sean necesarios para la gestión comercial y técnica, o hasta que corresponda eliminarlos. Ningún sistema conectado puede garantizar seguridad absoluta.

Contacto y solicitudes

Para consultas sobre esta política o solicitudes relacionadas con información administrada por el comercio, contactá a Autos Usados San Miguel por sus canales comerciales habituales.

Alcance

Este sitio es informativo y no contiene formularios propios de registro ni solicita datos de pago. Si en el futuro se incorporan funciones de recopilación directa, esta política deberá actualizarse antes de activarlas.
